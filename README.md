## 我怎样提 PR

- **先读规则**：`CONTRIBUTING`、PR 模板、AI 使用政策、CLA / DCO——确认这条路是允许的再动手。
- **先跑通再开口**：本地测试、构建或渲染验证通过才提 PR；不做「看起来改了」的改动。
- **小步可回滚**：一个 PR 只做一件事，带上复现步骤；配合作者 review，不催合并。
